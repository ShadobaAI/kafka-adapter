# Разработка адаптера

Здесь находятся инструкции по работе с исходниками самой подсистемы, тестовым контуром и релизами.

## С чего начать { #getting-started }

1. Найдите задачу или обсудите изменение. [Участие в разработке](contributing.md)
2. Подготовьте рабочий каталог, базовую конфигурацию и стенд для отладки. [Репозитории](repositories.md) · [Окружение](environment.md)
3. Найдите модуль или объект метаданных, который отвечает за нужный этап обмена. [Модули](modules.md) · [Метаданные](metadata.md) · [Управляющие константы](constants.md)
4. Выберите проверку для изменённого поведения. [Тестовые репозитории](repositories.md#testing) · [Релизный конвейер](release-ci.md)
5. Опишите изменение и результаты проверки в pull request. [Оформление изменений](contributing.md#pull-request)

# Форматы поставки

Подсистема поставляется в нескольких форматах — каждый для своей задачи.

## Как расширение конфигурации

| Файл | Назначение |
|------|------------|
| `kafka-adapter.cfe` | Файл расширения — подключается через «Расширения конфигурации» в Конфигураторе |
| `kafka-adapter-cfe-edt.zip` | Проект EDT расширения — для разработки и доработки |
| `kafka-adapter-cfe-xml.zip` | Исходники расширения в XML-формате Конфигуратора |

## Как часть основной конфигурации

| Файл | Назначение |
|------|------------|
| `kafka-adapter.cf` | Файл поставки конфигурации — для переноса через стандартный механизм поставки 1С |
| `kafka-adapter-cf-edt.zip` | Проект EDT конфигурации — для разработки и доработки |
| `kafka-adapter-cf-xml.zip` | Исходники конфигурации в XML-формате Конфигуратора |

## Демо-пример

| Файл | Назначение |
|------|-----------|
| `kafka-adapter-demo.dt` | Выгрузка информационной базы с настроенным примером интеграции — загружается через Конфигуратор |

## Что выбирать для разработки

- **Разработка адаптера** — работа напрямую с исходниками в каталоге `src/` через EDT.
- **Сборка релиза** — выгрузка в соответствующий формат через скрипты CI.
- **Прикладной разработчик, использующий адаптер** — см. [Установка и подключение](../user/installation/index.md) — выбирает CFE или CF; для работы с исходниками доступны архивы EDT и XML.

## Работа через библиотеки в EDT

Текущий конвейер выпуска не публикует файлы `.xlib` и `.clib`. Описанные инструкции подключения и обновления используют файлы CFE/CF и архивы исходников EDT. Если библиотека подготовлена отдельно, порядок её использования определяется этой поставкой.

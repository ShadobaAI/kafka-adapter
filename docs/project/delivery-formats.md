# Форматы поставки

Файлы доступны в [релизах kafka-adapter](https://github.com/ShadobaAI/kafka-adapter/releases).

| Файл | Когда использовать |
|---|---|
| `kafka-adapter.cfe` | Подключить расширение через Конфигуратор. |
| `kafka-adapter-cfe-edt.zip` | Открыть проект расширения в EDT. |
| `kafka-adapter-cfe-xml.zip` | Работать с XML-выгрузкой расширения в Конфигураторе. |
| `kafka-adapter.cf` | Сравнить и объединить объекты с основной конфигурацией. |
| `kafka-adapter-cf-edt.zip` | Открыть проект конфигурации в EDT. |
| `kafka-adapter-cf-xml.zip` | Работать с XML-выгрузкой конфигурации в Конфигураторе. |
| `kafka-adapter-demo.dt` | Развернуть демонстрационную информационную базу для знакомства со сценарием обмена. |

Для разработки адаптера используйте EDT-исходники из [репозитория адаптера](repositories.md#adapter). Порядок сборки приведён на странице [Сборка и проверка релиза](release-ci.md).

Для внедрения следуйте инструкции [как расширение](../user/installation/extension.md) или [в основную конфигурацию](../user/installation/main-config.md).

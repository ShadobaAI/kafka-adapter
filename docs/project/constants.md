# Управляющие константы

Изменяйте параметры через панель администрирования. Формы проверяют значения и выполняют сопутствующие операции.

| Константа | Назначение и настройка |
|---|---|
| `кфкИспользоватьИнтеграцию` | Включает подсистему. [Включение подсистемы](../user/configuration/index.md#enable-integration) |
| `кфкБлокировкаИнтеграции` | Управляет общей блокировкой обмена. [Фоновые задания](../user/configuration/jobs.md#background-jobs) |
| `кфкИспользоватьПотоковыйРежим` | Позволяет потокам ждать новые порции в том же фоновом задании. [Потоковый режим](../user/configuration/jobs.md#streaming-mode) |
| `кфкИспользоватьКонтрольИнтеграции` | Включает проверку ошибок и SLA. [Контроль интеграции](../user/configuration/alerts.md#integration-alerts) |
| `кфкКаталогЛогированияКомпоненты` | Путь на сервере 1С для файлов компоненты. [Каталог логов](../user/configuration/logging.md#connector-logging) |
| `кфкФорматИмениФайловЛогированияКомпоненты` | Шаблон даты в имени файлов компоненты. [Формат имён](../user/configuration/logging.md#connector-logging) |

# Диагностика

Выберите источник по этапу, на котором остановился обмен.

| Симптом | Что открыть | Что проверить |
|---|---|---|
| У сообщения статус **Ошибка обработки** или **Ошибка выгрузки** | Карточку записи в **Исходящих** или **Входящих сообщениях** | Поле **Текст журнала**, счётчики и время последней попытки. |
| Исходящая запись не появилась после записи объекта | Журнал регистрации 1С | Событие [регистрации при записи](#registration-event) и тип объекта в продюсере. |
| Не запускаются задания | **Kafka → Администрирование → Фоновые задания** и журнал регистрации 1С | Состояние потоков, блокировку и события задания под пользователем обмена. |
| Не удаётся подключиться к Kafka | [Файловые логи компоненты](../configuration/logging.md#connector-logging) | Адрес, сетевую ошибку, параметры SASL/TLS или ответ брокера. |
| Запись уже удалена из локальной очереди | Внешнее хранилище, если настроена [выгрузка журнала](../configuration/logging.md#external-logging) | `id` или ключ сообщения. Доступные поля зависят от настроек выгрузки и приёмника. |

## Ошибка регистрации при записи { #registration-event }

Адаптер перехватывает исключение в своей подписке и пишет событие `Адаптер Kafka.Регистрация при записи`. Откройте его в журнале регистрации 1С за время записи объекта и прочитайте подробности. При отсутствии события проверьте, настроена ли регистрация данного типа и пропускают ли её настройки продюсера. [Тип объекта в продюсере](../configuration/producers.md#registration-type)

## Как найти сообщение в Kafka { #find-kafka-message }

У входящего сообщения в карточке доступны топик, раздел и смещение. Эти три значения вместе адресуют сообщение. Kafka-ключ помогает искать связанные события, но может повторяться. Для исходящих записей имя топика ищите в правилах продюсера по типу объекта.

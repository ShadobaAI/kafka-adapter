# Разработка интеграции

Из серверного прикладного кода вызывайте методы `кфкИнтеграция`. Клиентская команда для открытия истории объекта находится в `кфкИнтеграцияКлиент`.

| Применить входящее сообщение в 1С | [Обработчик консьюмера](consumer-handler.md) |
| Вызвать Kafka из прикладного кода без очереди | [Прямой API](direct-api.md) |

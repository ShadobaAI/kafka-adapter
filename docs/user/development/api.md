# Программный API

Модуль **`кфкИнтеграция`** — основная точка входа для прикладного разработчика (серверный/клиент-серверный контекст). Модуль **`кфкИнтеграцияКлиент`** содержит клиентские процедуры открытия форм.

!!! warning "Публичный API"
    Из прикладного кода вызывайте **только** `кфкИнтеграция` и `кфкИнтеграцияКлиент`. Все модули с суффиксом `Служебный`, `СлужебныйВызовСервера` являются внутренним API — их сигнатуры и поведение могут меняться без предупреждения.

## Регистрация к обмену

### `Отключить(Источник)` { #disable-registration }

Добавляет в дополнительные свойства объекта признак пропуска автоматической регистрации.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `Источник` | `СправочникОбъект`, `ДокументОбъект`, `ПланВидовХарактеристикОбъект`, `ПланВидовРасчетаОбъект`, `ПланСчетовОбъект`, `БизнесПроцессОбъект`, `ЗадачаОбъект`, `ПланОбменаОбъект`, `РегистрСведенийНаборЗаписей`, `РегистрНакопленияНаборЗаписей`, `РегистрБухгалтерииНаборЗаписей`, `РегистрРасчетаНаборЗаписей` | Объект или набор записей регистра, подлежащий исключению |

**Возврат.** Нет.

!!! warning "Только до записи"
    Вызывайте `Отключить()` **до** записи объекта — в обработчике `ПередЗаписью` или непосредственно перед `Записать()`. Для уже созданной записи используйте команды очереди.

```bsl
кфкИнтеграция.Отключить(Источник);
```

Полный пример — [Подавление регистрации](../examples/suppress.md).

#### Флаг `"кфкПропуститьРегистрацию"` { #skip-registration-constant }

`Отключить()` реализован через служебный флаг в `ДополнительныеСвойства` объекта. Это **официальный механизм** — флаг можно установить и напрямую, без вызова API адаптера (например, в коде, который не должен зависеть от модулей подсистемы):

```bsl
Объект.ДополнительныеСвойства.Вставить("кфкПропуститьРегистрацию", Истина);
Объект.Записать();
```

Эффект идентичен `Отключить()`: подписки адаптера не поставят объект в очередь исходящих при этой записи.

!!! info "Совместимость с флагами БСП"
    Регистрация также пропускается, если в `ДополнительныеСвойства` установлены служебные флаги БСП `ОтключитьМеханизмРегистрацииОбъектов`, `НеВыполнятьКонтрольУдаляемых` или `СкрытиеКонфиденциальнойИнформации`.

### `ПоместитьВОчередьИсходящих(Источник, ТипОбъект, Продюсеры)` { #enqueue-outgoing }

Регистрирует объект, массив объектов или произвольное сообщение в очереди исходящих. **Основной способ программной отправки**.

| Параметр | Тип | Обяз. | По умолч. | Описание |
|----------|-----|-------|-----------|----------|
| `Источник` | `ЛюбаяСсылка`, объект, набор записей регистра, `Структура`, `Соответствие`, результат `ПараметрыСообщения()`, `Массив Из` перечисленных | да | — | Что регистрировать |
| `ТипОбъект` | `Строка` | нет | `""` | Ключ регистрации (см. ниже) |
| `Продюсеры` | `СправочникСсылка.кфкПродюсеры` или коллекция | нет | `Неопределено` | Ограничивает список продюсеров при регистрации. Настройте правила для используемого ключа. |

**Возврат.** Нет.

**Поведение.**

- При передаче **массива** — работает пакетный режим: сообщения разбиваются на порции, регистрация завершается порционно.
- При передаче результата `ПараметрыСообщения()` — прикладной обработчик сериализации пропускается. Структура или массив преобразуются в JSON при регистрации; строка и двоичные данные используются как есть.
- Если функциональная опция `кфкИспользоватьИнтеграцию` выключена — метод возвращается без действия.

**Параметр `ТипОбъект` — ключ регистрации.** Адаптер ищет продюсер, у которого значение в «Объектах метаданных» совпадает с этой строкой **без учёта регистра**. Подстроки и маски не применяются. Может быть полным именем метаданных (`Справочник.Номенклатура`) или произвольным ключом (`crm.order-placed`). Подробно — [Тип объект — ключ регистрации](../configuration/producers.md#registration-type).

```bsl
// Одиночная ссылка
кфкИнтеграция.ПоместитьВОчередьИсходящих(СсылкаНаДокумент);

// Массив (пакетный режим)
кфкИнтеграция.ПоместитьВОчередьИсходящих(МассивСсылок);

// Произвольное сообщение
Сообщение = кфкИнтеграция.ПараметрыСообщения("{""event"":""ping""}", "msg-1");
кфкИнтеграция.ПоместитьВОчередьИсходящих(Сообщение, "system.events");
```

Примеры — [Принудительная регистрация](../examples/force-registration.md), [Произвольные события](../examples/custom-events.md).

### `КлючОбъекта(Данные)` { #object-key }

Возвращает уникальный ключ объекта, используемый адаптером для идентификации в исходящих сообщениях.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `Данные` | `ЛюбаяСсылка`, `СправочникОбъект`, `ДокументОбъект`, `РегистрСведенийКлючЗаписи`, `РегистрНакопленияКлючЗаписи` | Данные для идентификации |

**Возврат.** `Строка` (ключ) или `Неопределено`.

### `КлючЗаписиИсходящихСообщений(Данные)` { #outgoing-record-keys }

Возвращает массив ключей записей в регистре исходящих, относящихся к данным.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `Данные` | `ЛюбаяСсылка`, `СправочникОбъект`, `ДокументОбъект`, `РегистрСведенийКлючЗаписи` | Данные для поиска |

**Возврат.** `Массив Из Строка` или `Неопределено`.

## События регистрации

Используются в обработчике продюсера, чтобы различать источник попадания сообщения в очередь.

### `ЭтоРегистрацияПриЗаписи(Свойства)` { #is-write-registration }

Возвращает `Истина`, если сообщение было зарегистрировано **подпиской на событие записи** объекта.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `Свойства` | `Структура` | Свойства сообщения, `Свойства.СобытиеРегистрации` — `ПеречислениеСсылка.кфкСобытияРегистрации` |

**Возврат.** `Булево`. Бросает исключение, если `СобытиеРегистрации` не указано.

### `ЭтоРегистрацияПрограммно(Свойства)` { #is-api-registration }

Возвращает `Истина`, если сообщение было зарегистрировано через API `ПоместитьВОчередьИсходящих`.

### `ЭтоРегистрацияПринудительно(Свойства)` { #is-forced-registration }

Возвращает `Истина`, если сообщение было зарегистрировано **вручную** через UI «Регистрация изменений» или эквивалентный механизм.

```bsl
Если кфкИнтеграция.ЭтоРегистрацияПриЗаписи(Свойства) Тогда
    // зарегистрировано подпиской
ИначеЕсли кфкИнтеграция.ЭтоРегистрацияПрограммно(Свойства) Тогда
    // зарегистрировано API
ИначеЕсли кфкИнтеграция.ЭтоРегистрацияПринудительно(Свойства) Тогда
    // зарегистрировано вручную через UI
КонецЕсли;
```

## Конструкторы

### `ПараметрыСообщения(Данные, Ключ)` { #message-parameters }

Формирует описание сообщения для последующей передачи в `Отправить()` или `ПоместитьВОчередьИсходящих()`.

| Параметр | Тип | По умолч. | Описание |
|----------|-----|-----------|----------|
| `Данные` | `Строка`, `ДвоичныеДанные`, `Структура`, `Массив Из Структура` | `""` | Тело сообщения |
| `Ключ` | `Строка` | `""` | Kafka-ключ сообщения |

**Возврат.** Структура:

| Поле | Тип | Описание |
|------|-----|----------|
| `Данные` | см. выше | Тело сообщения |
| `Ключ` | `Строка` | Идентификатор |
| `Заголовки` | `Соответствие Из КлючИЗначение` | Пустое соответствие для добавления заголовков |

```bsl
Сообщение = кфкИнтеграция.ПараметрыСообщения(СтрокаJSON, "Order-123");
Сообщение.Заголовки.Вставить("source", "crm");
```

### `РезультатИнтеграции()` { #integration-result }

Формирует пустой результат операции. Используется вспомогательным кодом; прикладному разработчику обычно не нужен напрямую.

**Возврат.** Структура `{Успешно: Ложь, ТекстОшибки: ""}`.

## Интеграция с подсистемами БСП { #bsp-integration }

Методы вызываются из соответствующих процедур переопределяемых модулей БСП. Порядок подключения в основную конфигурацию или расширение и примеры приведены в разделе [Адаптация подсистемы](../installation/adaptation.md#bsp-setup).

### `ПриОпределенииНастроекРегламентныхЗаданий(Настройки)` { #scheduled-job-hook }

Добавляет в переданную таблицу настройки задания `кфкЗапускИнтеграции`: зависимость от функциональной опции `кфкИспользоватьИнтеграцию` и признак `РаботаетСВнешнимиРесурсами = Истина`.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `Настройки` | `ТаблицаЗначений` | Таблица настроек из `РегламентныеЗаданияПереопределяемый.ПриОпределенииНастроекРегламентныхЗаданий`; состав колонок определяется БСП |

**Возврат.** Нет. Настройки добавляются в переданную таблицу.

!!! warning "Обязателен при подключении адаптера"
    Вызывайте метод из `РегламентныеЗаданияПереопределяемый.ПриОпределенииНастроекРегламентныхЗаданий`. Он необходим для включения задания в штатную защиту внешних ресурсов БСП, в том числе при копировании или переносе информационной базы, и для учета функциональной опции. Проверка в начале выполнения задания не заменяет регистрацию этих настроек. Индивидуальные разрешения запуска обрабатываются штатным механизмом БСП.

```bsl
кфкИнтеграция.ПриОпределенииНастроекРегламентныхЗаданий(Настройки);
```

### `ПриДобавленииОбработчиковУстановкиПараметровСеанса(Обработчики)` { #session-parameter-hook }

Добавляет обработчик установки параметра сеанса `кфкСчетчикКомбинированнойМетки`. При обращении к неинициализированному параметру БСП вызывает обработчик, который устанавливает счётчик в `0` и добавляет имя параметра в список установленных.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `Обработчики` | `Соответствие` | Соответствие имён параметров сеанса и имён методов их установки из обработчика БСП |

**Возврат.** Нет. Обработчик добавляется в переданное соответствие.

!!! warning "Обязателен при подключении адаптера"
    Вызывайте метод из `ОбщегоНазначенияПереопределяемый.ПриДобавленииОбработчиковУстановкиПараметровСеанса`, передавая `Обработчики` без изменений. Это позволяет БСП инициализировать счётчик, используемый для формирования комбинированных меток, до его чтения. Примеры для основной конфигурации и расширения приведены в разделе [Параметры сеанса](../installation/adaptation.md#session-parameters).

```bsl
кфкИнтеграция.ПриДобавленииОбработчиковУстановкиПараметровСеанса(Обработчики);
```

### `ПриОпределенииКомандПодключенныхКОбъекту(НастройкиФормы, Источники, ПодключенныеОтчетыИОбработки, Команды)` { #connected-commands-hook }

Добавляет команду **«История выгрузки (Kafka)»** в меню **«Еще»** форм объектов, участвующих в интеграции. Команда зависит от функциональной опции `кфкИспользоватьИнтеграцию`, не поддерживает множественный выбор и использует режим записи `ЗаписыватьТолькоНовые`.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `НастройкиФормы` | `Структура` | Сведения о форме из обработчика БСП |
| `Источники` | `ДеревоЗначений` | Поставщики команд формы |
| `ПодключенныеОтчетыИОбработки` | `ТаблицаЗначений` | Отчеты и обработки, предоставляющие команды |
| `Команды` | `ТаблицаЗначений` | Таблица, в которую добавляется команда |

!!! warning "Обязателен при использовании подключаемых команд"
    Если в конфигурации внедрена подсистема БСП «Подключаемые команды», обязательно вызывайте метод из `ПодключаемыеКомандыПереопределяемый.ПриОпределенииКомандПодключенныхКОбъекту`, передавая параметры без изменений. Иначе команда истории выгрузки не будет добавлена в формы через этот механизм.

Состав параметров определяется контрактом процедуры БСП; сформированный список команд кэшируется БСП по именам форм.

**Возврат.** Нет. Команда добавляется в переданную таблицу `Команды`.

```bsl
кфкИнтеграция.ПриОпределенииКомандПодключенныхКОбъекту(
    НастройкиФормы, Источники, ПодключенныеОтчетыИОбработки, Команды);
```

## Клиентские методы (`кфкИнтеграцияКлиент`)

### `ИсторияВыгрузкиОбъекта(Данные, Форма, Окно, РежимОткрытияОкна)` { #object-export-history }

Открывает форму очереди исходящих сообщений с отбором по объекту. Удобно встраивать в формы объектов кнопкой «История выгрузки».

| Параметр | Тип | Обяз. | По умолч. | Описание |
|----------|-----|-------|-----------|----------|
| `Данные` | `ЛюбаяСсылка`, `СправочникОбъект`, `ДокументОбъект`, `РегистрСведенийКлючЗаписи` | да | — | Данные для поиска записей |
| `Форма` | `ФормаКлиентскогоПриложения` | нет | `Неопределено` | Форма-владелец |
| `Окно` | `ОкноКлиентскогоПриложения` | нет | `Неопределено` | Окно приложения, в котором открыть форму |
| `РежимОткрытияОкна` | `РежимОткрытияОкнаФормы` | нет | `БлокироватьОкноВладельца` | Режим открытия |

**Возврат.** Нет. Если по `Данные` не найдены записи в очереди — форма не открывается.

```bsl
&НаКлиенте
Процедура ИсторияВыгрузки(Команда)
    кфкИнтеграцияКлиент.ИсторияВыгрузкиОбъекта(Объект.Ссылка, ЭтаФорма);
КонецПроцедуры
```

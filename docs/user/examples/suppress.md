# Подавление регистрации при записи

Чтобы изменение, применённое импортом, не стало исходящим событием, установите признак пропуска автоматической регистрации перед `Записать()`. Признак относится к переданному объекту или набору записей.

## Через API адаптера { #with-api }

```bsl
кфкИнтеграция.Отключить(Объект);
Объект.Записать();
```

Этот вызов можно сделать в обработчике консьюмера, в коде импорта или в обработчике `ПередЗаписью`, когда признак импорта уже известен.

## Через дополнительные свойства { #with-properties }

```bsl
Объект.ДополнительныеСвойства.Вставить("кфкПропуститьРегистрацию", Истина);
Объект.Записать();
```

Подписка проверяет наличие свойства. При последующих записях того же экземпляра проверьте, должен ли признак оставаться установленным.

Чтобы проверить результат, запишите объект с признаком и сравните исходящую очередь с предыдущей записью того же типа. Новая регистрация от этой записи не должна появиться.

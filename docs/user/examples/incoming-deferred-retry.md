# Отложенная обработка заказа

Заказ и контрагент приходят из разных топиков. Если заказ получен первым, обработчик оставляет сообщение в очереди и запрашивает повтор с задержкой 60 секунд от начала попытки. После загрузки контрагента заказ можно записать с его ссылкой.

## Входные данные { #input }

В примере используются документ `ЗаказКлиента` с реквизитом `Контрагент` и справочник `Контрагенты`. Замените их именами из своей конфигурации и заполните обязательные реквизиты документа. Загрузчик контрагентов должен сохранять UUID из обмена как UUID ссылки элемента.

```json
{
  "ref": "80eaf6ee-29cc-44bb-997d-5a0a44ccc9c3",
  "customerRef": "75d13567-88a8-44af-b22f-b136545cfaf2",
  "dateTime": "2026-07-06T10:00:00"
}
```

## Настройка и код { #handler }

Для топика заказов укажите **Произвольный обработчик** и метод `ОбменЗаказамиСервер.ДесериализацияЗаказа`. Выключите флаг **Двоичные данные**, чтобы метод получил строку JSON. Разместите процедуру в серверном общем модуле `ОбменЗаказамиСервер`.

```bsl
Процедура ДесериализацияЗаказа(ТелоСообщения, Свойства, ТекстЖурнала, Отказ) Экспорт

    Данные = ОбщегоНазначения.JSONВЗначение(ТелоСообщения, "dateTime", Ложь);
    СсылкаКонтрагента = Справочники.Контрагенты.ПолучитьСсылку(
        Новый УникальныйИдентификатор(Данные.customerRef));

    Если Не ОбщегоНазначения.СсылкаСуществует(СсылкаКонтрагента) Тогда
        ТекстЖурнала = "Контрагент ещё не загружен";
        Свойства.ВремяОжидания = 60;
        Отказ = Неопределено;
        Возврат;
    КонецЕсли;

    СсылкаЗаказа = Документы.ЗаказКлиента.ПолучитьСсылку(
        Новый УникальныйИдентификатор(Данные.ref));
    Заказ = СсылкаЗаказа.ПолучитьОбъект();
    Если Заказ = Неопределено Тогда
        Заказ = Документы.ЗаказКлиента.СоздатьДокумент();
        Заказ.УстановитьСсылкуНового(СсылкаЗаказа);
    КонецЕсли;

    Заказ.Дата = Данные.dateTime;
    Заказ.Контрагент = СсылкаКонтрагента;

    кфкИнтеграция.Отключить(Заказ);
    Заказ.Записать();

КонецПроцедуры
```

## Проверка { #verification }

1. Опубликуйте заказ для UUID контрагента, которого ещё нет в базе. После вызова обработчика проверьте статус **Новое**, текст журнала и значение **60** в поле **Задержка, с**.
2. Загрузите контрагента с этим UUID. При очередной попытке после задержки запись должна перейти в **Обработано**, а заказ должен содержать ссылку на загруженного контрагента.
3. Чтобы проверить повторный вызов, опубликуйте такой же заказ при выключенной проверке хэшей у консьюмера. Обработчик обновит заказ с существующим UUID.

Правила отсчёта и лимиты приведены в [контракте обработчика](../development/consumer-handler.md#deferred-retry).

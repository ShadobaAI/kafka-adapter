# Отмена обработки с сохранением причины

**Сценарий.** Сообщение невалидно (нет обязательного поля, неизвестный формат) — нужно **отменить** обработку и **сохранить** причину отказа для последующего разбора.

## Код обработчика

```bsl
Процедура Десериализация(ТелоСообщения, Свойства, ТекстЖурнала, Отказ) Экспорт

    Данные = ОбщегоНазначения.JSONВЗначение(ТелоСообщения, "", Ложь);

    Если ТипЗнч(Данные) <> Тип("Структура") Тогда

        ТекстЖурнала = "Корневое значение JSON должно быть объектом";
        Отказ = Истина;
        Возврат;

    КонецЕсли;

    ЗначениеRef = Неопределено;
    Если Не Данные.Свойство("ref", ЗначениеRef) Или Не ЗначениеЗаполнено(ЗначениеRef) Тогда

        ТекстЖурнала = СтрШаблон(
            "Отсутствует поле 'ref'. Топик: %1, смещение: %2",
            Свойства.Топик,
            Свойства.Смещение
        );
        Отказ = Истина;
        Возврат;

    КонецЕсли;

    // ... основная обработка ...

КонецПроцедуры
```

## Что происходит при `Отказ = Истина`

- При успешном завершении обработчика сообщение получает статус **«Обработка отменена»** в РС «Входящие сообщения». Исключение или неуспешное выполнение обработчика приводит к статусу **«Ошибка обработки»**.
- Текст из `ТекстЖурнала` сохраняется в записи и доступен в поле **Текст журнала**.
- **Автоматический повтор не запускается** — администратор разбирает ошибку вручную.
- После устранения причины — кнопка **Вернуть в очередь** в РС «Входящие сообщения».

## Идемпотентность

!!! warning "Повторный вызов"
    Обработчик может быть вызван повторно при перезапуске или ручном возврате. Проектируйте его так, чтобы повторный вызов с тем же сообщением **не создавал дубликаты** и не вызывал побочных эффектов.

    Проверки на валидность (как в примере выше) **идемпотентны по определению** — одно и то же сообщение даёт один и тот же результат.

## Разные причины отказа — разные обработки

```bsl
Процедура Десериализация(ТелоСообщения, Свойства, ТекстЖурнала, Отказ) Экспорт

    Попытка
        Данные = ОбщегоНазначения.JSONВЗначение(ТелоСообщения, "", Ложь);
    Исключение
        ТекстЖурнала = "Некорректный JSON: "
            + ОбработкаОшибок.ПодробноеПредставлениеОшибки(ИнформацияОбОшибке());
        Отказ = Истина;
        Возврат;
    КонецПопытки;

    Если ТипЗнч(Данные) <> Тип("Структура") Тогда

        ТекстЖурнала = "Корневое значение JSON должно быть объектом";
        Отказ = Истина;
        Возврат;

    КонецЕсли;

    ЗначениеRef = Неопределено;
    Если Не Данные.Свойство("ref", ЗначениеRef) Или Не ЗначениеЗаполнено(ЗначениеRef) Тогда

        ТекстЖурнала = "Отсутствует поле 'ref'";
        Отказ = Истина;
        Возврат;

    КонецЕсли;

    Версия = Неопределено;
    Если Не Данные.Свойство("version", Версия) Тогда

        ТекстЖурнала = "Отсутствует поле 'version'";
        Отказ = Истина;
        Возврат;

    КонецЕсли;

    Если ТипЗнч(Версия) <> Тип("Число") Тогда

        ТекстЖурнала = "Поле 'version' должно быть числом";
        Отказ = Истина;
        Возврат;

    КонецЕсли;

    Если Версия > МаксимальнаяВерсия() Тогда

        ТекстЖурнала = СтрШаблон("Неподдерживаемая версия контракта: %1", Версия);
        Отказ = Истина;
        Возврат;

    КонецЕсли;

    // ... основная обработка ...

КонецПроцедуры
```

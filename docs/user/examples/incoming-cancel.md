# Отмена обработки с сохранением причины

Если сообщение не проходит проверку формата, обработчик может завершить обработку со статусом **Обработка отменена** и оставить пояснение в журнале.

## Обработчик { #handler }

Настройте топик на **Произвольный обработчик** с текстовым телом и укажите имя процедуры. В этом примере отмена происходит для некорректного JSON и для объекта без обязательного поля `ref`.

```bsl
Процедура Десериализация(ТелоСообщения, Свойства, ТекстЖурнала, Отказ) Экспорт

    Попытка
        Данные = ОбщегоНазначения.JSONВЗначение(ТелоСообщения, "", Ложь);
    Исключение
        ТекстЖурнала = "Тело сообщения не удалось прочитать как JSON";
        Отказ = Истина;
        Возврат;
    КонецПопытки;

    Если ТипЗнч(Данные) <> Тип("Структура") Тогда
        ТекстЖурнала = "Корневое значение JSON должно быть объектом";
        Отказ = Истина;
        Возврат;
    КонецЕсли;

    ЗначениеRef = Неопределено;
    Если Не Данные.Свойство("ref", ЗначениеRef) Или Не ЗначениеЗаполнено(ЗначениеRef) Тогда
        ТекстЖурнала = СтрШаблон(
            "Не заполнено поле 'ref'. Топик %1, раздел %2, смещение %3",
            Свойства.Топик,
            Свойства.Раздел,
            Свойства.Смещение);
        Отказ = Истина;
        Возврат;
    КонецЕсли;

    // Выполните прикладную обработку после проверок.

КонецПроцедуры
```

## Проверка { #verification }

Отправьте `{}`. В карточке входящего сообщения должен появиться статус **Обработка отменена** и причина в поле **Текст журнала**. Исключение, вышедшее из обработчика, приводит к статусу **Ошибка обработки**.

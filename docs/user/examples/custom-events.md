# Отправка произвольного события

Опубликуйте из прикладного кода JSON о завершении операции. Для события используется отдельный ключ регистрации `system.events`.

## Настройка продюсера { #producer-setup }

Добавьте строку в таблицу **Объекты метаданных**. В колонке **Тип объект** укажите `system.events`, в **Имя топика** — `system-events`. Для готового тела из `ПараметрыСообщения` адаптер пропускает вызов сериализатора.

## Код и проверка { #send-event }

```bsl
Идентификатор = Строка(Новый УникальныйИдентификатор);
Данные = Новый Структура("id, event", Идентификатор, "maintenance.completed");
Сообщение = кфкИнтеграция.ПараметрыСообщения(Данные, Идентификатор);
Сообщение.Заголовки.Вставить("content-type", "application/json");
Сообщение.Заголовки.Вставить("version", "1");

кфкИнтеграция.ПоместитьВОчередьИсходящих(Сообщение, "system.events");
```

После вызова проверьте исходящую очередь. Готовое тело сразу допускается к выгрузке. После статуса **Выгружено** найдите событие в топике по идентификатору. [Маршрутизация по ключу](../configuration/producers.md#registration-type)

## Как получать ссылку на продюсер { #find-producer }

| Где работает код | Откуда взять ссылку |
|---|---|
| Постановка готового события в очередь | Достаточно передать ключ регистрации. Адаптер выбирает продюсеров по настройкам. |
| Обработчик продюсера | Используйте `Свойства.Продюсер`. |
| Прямой API | Храните ссылку в настройках прикладного решения и передавайте её в `Отправить`. |

# Сериализация независимого регистра сведений

Адаптер регистрирует записи набора независимого регистра по одной. Произвольный обработчик получает структуру одной регистрации. Ниже регистр имеет измерение `Номенклатура` и ресурс `Количество`.

## Настройка и код { #handler }

В **Тип объект** продюсера укажите полное имя регистра, например `РегистрСведений.ОстаткиИзKafka`. Выберите топик и экспортную функцию **Произвольного обработчика**.

```bsl
Функция СериализоватьОстаток(Объект, Свойства, ТекстЖурнала, Отказ) Экспорт

    Данные = Новый Структура("deleted", Свойства.ЭтоУдаление);
    Номенклатура = Неопределено;
    Если Объект.Свойство("Номенклатура", Номенклатура) Тогда
        Данные.Вставить("ref", Строка(Номенклатура.УникальныйИдентификатор()));
    КонецЕсли;

    Если Не Свойства.ЭтоУдаление Тогда
        Данные.Вставить("qty", Объект.Количество);
    КонецЕсли;

    Возврат кфкИнтеграция.ПараметрыСообщения(Данные);

КонецФункции
```

Для регистрации пустого набора структура содержит значения отбора. Согласуйте, какие поля получатель будет использовать для идентификации удаляемых данных. Если регистр периодический, добавьте период, когда он присутствует в структуре.

## Проверка { #verification }

Запишите набор с двумя разными ключами. В исходящей очереди должны появиться две регистрации. Проверьте тело обычной записи и отдельно проверьте поле `deleted` при записи пустого набора с отбором по одному ключу.

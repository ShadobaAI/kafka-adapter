# Защищённое подключение { #secure-connection }

Примеры параметров подключения для защищённых кластеров Kafka. Все параметры задаются в справочнике **[Брокеры](../configuration/brokers.md)**, табличная часть **Параметры подключения**.

## SASL/PLAIN

Простой механизм имя+пароль. Для передачи имени и пароля по TLS используйте `SASL_SSL` с механизмом `PLAIN`.

| Ключ | Значение | Режим пароля |
|------|----------|:---:|
| `security.protocol` | `SASL_SSL` | |
| `sasl.mechanism` | `PLAIN` | |
| `sasl.username` | `<имя пользователя>` | |
| `sasl.password` | `<пароль>` | :material-check: |

Если в кластере используется собственный центр сертификации, укажите `ssl.ca.location`.

## SASL/SCRAM

Выберите `SCRAM-SHA-256` или `SCRAM-SHA-512` в соответствии с настройкой учётной записи Kafka.

| Ключ | Значение | Режим пароля |
|------|----------|:---:|
| `security.protocol` | `SASL_SSL` | |
| `sasl.mechanism` | `SCRAM-SHA-512` | |
| `sasl.username` | `<имя пользователя>` | |
| `sasl.password` | `<пароль>` | :material-check: |

## SSL/TLS (клиентские сертификаты)

Взаимная аутентификация: клиент и сервер подтверждают друг друга сертификатами.

| Ключ | Значение | Режим пароля |
|------|----------|:---:|
| `security.protocol` | `SSL` | |
| `ssl.ca.location` | `/etc/kafka/certs/ca.pem` | |
| `ssl.certificate.location` | `/etc/kafka/certs/client.pem` | |
| `ssl.key.location` | `/etc/kafka/certs/client.key` | |
| `ssl.key.password` | `<пароль ключа>` | :material-check: |

## Требования к путям файлов

- Пути указываются в **файловой системе сервера 1С** (а не рабочей станции клиента).
- Файлы должны быть **доступны на чтение** пользователю, от имени которого работает процесс сервера 1С.
- Разместите нужные файлы по указанным путям на каждом сервере 1С, где может запускаться обмен.

## Общие рекомендации

!!! tip "Включайте «Режим пароля»"
    Для всех полей с секретными значениями (`sasl.password`, `ssl.key.password`, токены) включайте **Режим пароля** чтобы значение маскировалось при показе формы.

!!! info "Полный список параметров librdkafka"
    [CONFIGURATION.md — librdkafka](https://github.com/confluentinc/librdkafka/blob/master/CONFIGURATION.md)

!!! warning "Диагностика"
    При проблемах с подключением проверяйте **логи внешней компоненты** — путь задаётся в **Kafka / Администрирование / Логирование**, поле **Каталог**. Там будут детальные сообщения librdkafka о рукопожатии TLS, SASL и т.п.

# Регистрация исходящих из кода

Вызовите `кфкИнтеграция.ПоместитьВОчередьИсходящих`, чтобы зарегистрировать данные без записи объекта. Для ссылки адаптер подбирает продюсеров по имени метаданных, если второй параметр опущен.

## Одна ссылка или массив { #references }

```bsl
кфкИнтеграция.ПоместитьВОчередьИсходящих(СсылкаНаНоменклатуру);

МассивСсылок = Запрос.Выполнить().Выгрузить().ВыгрузитьКолонку("Ссылка");
кфкИнтеграция.ПоместитьВОчередьИсходящих(МассивСсылок);
```

Адаптер пишет элементы массива порциями. Для большой выборки учитывайте память вызывающего процесса и границы его транзакции. Если вы сначала записываете объекты и хотите зарегистрировать их только вызовом API, [подавите автоматическую регистрацию](suppress.md) перед записью.

## Готовое сообщение по ключу { #message-routing }

Задайте в продюсере строку с ключом `system.events` и топиком. Затем сформируйте готовое сообщение и укажите этот ключ вторым параметром.

```bsl
Сообщение = кфкИнтеграция.ПараметрыСообщения("{""event"":""ping""}", "ping-01");
кфкИнтеграция.ПоместитьВОчередьИсходящих(Сообщение, "system.events");
```

Проверьте, что появилась запись с событием **Программно**. Для ссылки запись проходит сериализацию, а готовое тело можно сразу выгружать. При повторной регистрации учитывайте [дедупликацию](../configuration/producers.md#registration-deduplication).

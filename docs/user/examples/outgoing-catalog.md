# Сериализация справочника

При записи элемента `Номенклатура` адаптер формирует JSON с его UUID, кодом и наименованием.

## Настройка продюсера { #producer-setup }

В таблицу **Объекты метаданных** добавьте строку со значениями из таблицы. Реализуйте экспортную функцию в серверном общем модуле `ОбменKafkaСервер`.

| Поле | Значение |
|---|---|
| **Тип объект** | `Справочник.Номенклатура` |
| **Имя топика** | `catalog` |
| **Тип сериализации** | **Произвольный обработчик** |
| **Имя метода сериализации** | `ОбменKafkaСервер.СериализоватьНоменклатуру` |

## Код обработчика { #handler }

```bsl
Функция СериализоватьНоменклатуру(Объект, Свойства, ТекстЖурнала, Отказ) Экспорт

    Идентификатор = Строка(Объект.Ссылка.УникальныйИдентификатор());
    Данные = Новый Структура("ref, code, name, deleted",
        Идентификатор, Объект.Код, Объект.Наименование, Свойства.ЭтоУдаление);

    Возврат кфкИнтеграция.ПараметрыСообщения(Данные, Идентификатор);

КонецФункции
```

Пример рассчитан на автоматическую регистрацию объекта при записи. Если вы также регистрируете ссылки программно, учтите тип [входных данных обработчика](../development/producer-handler.md#handler-input).

## Проверка { #verification }

1. Запишите элемент. В **Исходящих сообщениях** найдите запись по объекту.
2. После успешной отправки проверьте статус **Выгружено** и сообщение в `catalog`. Поле `ref` и Kafka-ключ должны содержать UUID элемента.

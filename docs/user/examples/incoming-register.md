# Запись в независимый регистр сведений

Пример загружает количество в периодический независимый регистр `ОстаткиИзKafka` с измерением `Номенклатура` и ресурсом `Количество`. В сообщении `period` — дата в ISO 8601, `ref` — UUID существующей номенклатуры, `qty` — число.

## Код обработчика { #handler }

Укажите полный путь к экспортной процедуре в настройке топика. Для JSON-строки выключите **Двоичные данные**.

```bsl
Процедура ЗагрузитьОстаток(ТелоСообщения, Свойства, ТекстЖурнала, Отказ) Экспорт

    Данные = ОбщегоНазначения.JSONВЗначение(ТелоСообщения, "period", Ложь);
    Номенклатура = Справочники.Номенклатура.ПолучитьСсылку(
        Новый УникальныйИдентификатор(Данные.ref));

    Набор = РегистрыСведений.ОстаткиИзKafka.СоздатьНаборЗаписей();
    СтрокаРегистра = Набор.Добавить();
    СтрокаРегистра.Период = Данные.period;
    СтрокаРегистра.Номенклатура = Номенклатура;
    СтрокаРегистра.Количество = Данные.qty;

    кфкИнтеграция.Отключить(Набор);
    Набор.Записать(РежимЗамещения.Слияние);

КонецПроцедуры
```

Подставьте имена своего регистра и заполните все измерения. `Слияние` ищет запись по полному ключу, включая период у периодического регистра. Для непериодического регистра уберите заполнение `Период`.

## Проверка { #verification }

Загрузите два сообщения с одинаковыми `period` и `ref`, но разным `qty`. В регистре должна остаться одна запись с обновлённым количеством. [Контракт обработчика консьюмера](../development/consumer-handler.md)

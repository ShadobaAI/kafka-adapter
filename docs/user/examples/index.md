# Примеры

Для обмена через очереди [подключите адаптер](../installation/index.md), включите подсистему и настройте [брокер](../configuration/brokers.md). Имена прикладных объектов и топиков в примерах замените своими. Демонстрационные реализации API есть в [репозитории примеров](https://github.com/ShadobaAI/kafka-adapter-examples).

|---|---|

| Отправлять по одному сообщению на строку | [Разделение табличных данных](outgoing-split-rows.md) |
| Отправить запись независимого регистра | [Независимый регистр сведений](outgoing-register.md) |
| Отправить движения по регистратору | [Регистр по регистратору](outgoing-recorder.md) |
| Пропустить регистрацию при записи | [Подавление регистрации](suppress.md) |
| Зарегистрировать запись или массив ссылок из кода | [Программная регистрация](force-registration.md) |

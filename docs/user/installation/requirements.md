# Требования

## Сервер 1С { #one-c-server }

| Компонент | Требование |
|---|---|
| Платформа | 1С:Предприятие 8.3.26 или новее. Режим совместимости адаптера — 8.3.21. |
| Информационная база | Клиент-серверный режим. |
| Лицензия 1С | ПРОФ или КОРП. Условия создания дополнительных индексов описаны в [разделе о производительности](../operations/performance.md#additional-indexes). |
| ОС | Windows x64 или Linux x64. На Linux требуется glibc 2.28 или новее. |
| БСП | 1С:Библиотека стандартных подсистем 3.1.10 или новее в целевой конфигурации. |
| Kafka-клиент | [Simple Kafka Connector 1C](https://github.com/NuclearAPK/Simple-Kafka_Adapter) входит в поставку адаптера. |
| Работа с конфигурацией | EDT или Конфигуратор. |

## Кластер Kafka { #kafka-cluster }

Сервер 1С должен иметь сетевой доступ к Kafka. Подготовьте адреса bootstrap-серверов, топики и права на нужные операции. Если кластер использует SASL или TLS, подготовьте параметры аутентификации и сертификаты. [Брокеры](../configuration/brokers.md) · [Пример защищённого подключения](../examples/secure-connection.md)

## Дополнительные компоненты { #optional-components }

- **Конвертация данных 3.1.** Нужны доступный XDTO-пакет и модуль обмена с правилами для выбранного формата. [Настройка КД 3.1](../development/conversion-data.md)
- **Внешние логи.** Для выгрузки журнала нужен HTTP-приёмник с поддержкой формата адаптера. [Контракт выгрузки](../configuration/logging.md#external-logging)

После проверки требований [выберите способ подключения](index.md#compare-installation).

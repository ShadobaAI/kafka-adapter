# Настройка в EDT / Конфигураторе

Свяжите метаданные адаптера со справочником пользователей и обработчиками БСП целевой конфигурации. При обновлении [проверьте эти подключения](updating.md#adaptation-check).

## Определяемый тип `кфкПользователь` { #user-defined-type }

Тип `кфкПользователь` используется для ссылок на пользователей, в том числе для выбора пользователя обмена. Проверьте привязку к справочнику пользователей целевой конфигурации.

!!! warning "Обязательно заменить"
    При внедрении в прикладную конфигурацию **замените** тип на `СправочникСсылка.Пользователи` **целевой** конфигурации (обычно он есть в БСП — `Справочник.Пользователи`).

### Как заменить

=== "EDT"

    1. Откройте дерево → **Общие → Определяемые типы → `кфкПользователь`**.
    2. Двойным щелчком откройте тип.
    3. В окне «Тип данных» укажите справочник пользователей целевой конфигурации (в типовых конфигурациях — обычно `СправочникСсылка.Пользователи`).
    4. Сохраните проект.
    5. Обновите конфигурацию базы данных.

=== "Конфигуратор"

    1. Откройте дерево конфигурации → **Общие → Определяемые типы → `кфкПользователь`**.
    2. Двойным щелчком откройте тип.
    3. В окне «Тип данных» укажите справочник пользователей целевой конфигурации (в типовых конфигурациях — обычно `СправочникСсылка.Пользователи`).
    4. Обновите конфигурацию базы данных.

## Источники подписок { #subscription-sources }

[Подписки адаптера](../../project/modules.md#event-subscriptions) охватывают поддерживаемые типы объектов и наборов записей. Настройки продюсера определяют, какие из этих объектов регистрировать. Если пришлось сузить источники подписки в метаданных, включайте нужные типы и в подписку, и в настройки продюсера.

## Подключение к подсистемам БСП { #bsp-setup }

Подключите методы общего модуля `кфкИнтеграция` к соответствующим обработчикам БСП целевой конфигурации. Передавайте параметры обработчиков без изменений.

!!! warning "Обязательные подключения"
    Подключения регламентного задания и параметров сеанса обязательны. Подключение команд обязательно, если в конфигурации внедрена подсистема БСП «Подключаемые команды». Проверьте эти подключения и тип `кфкПользователь` при каждом [обновлении адаптера](updating.md#adaptation-check).

### Регламентные задания { #scheduled-jobs }

!!! warning "Обязательное подключение регламентного задания"
    Обязательно подключите `кфкИнтеграция.ПриОпределенииНастроекРегламентныхЗаданий` при внедрении адаптера. Без этого вызова адаптер не передает БСП признак работы задания с внешними ресурсами и его зависимость от функциональной опции. Нельзя рассчитывать на штатное отключение задания БСП при блокировке внешних ресурсов только на основании проверки в начале выполнения задания.

В процедуре `РегламентныеЗаданияПереопределяемый.ПриОпределенииНастроекРегламентныхЗаданий` добавьте вызов:

```bsl
кфкИнтеграция.ПриОпределенииНастроекРегламентныхЗаданий(Настройки);
```

Метод связывает задание `кфкЗапускИнтеграции` с функциональной опцией `кфкИспользоватьИнтеграцию` и устанавливает `РаботаетСВнешнимиРесурсами = Истина`. Это подключает задание к штатным проверкам доступности и блокировки внешних ресурсов БСП. Условия запуска описаны в разделе [Регламентное задание](../configuration/jobs.md#scheduled-job).

### Параметры сеанса { #session-parameters }

!!! warning "Обязательная инициализация параметра сеанса"
    При формировании комбинированных меток адаптер использует счётчик `кфкСчетчикКомбинированнойМетки`. Вызов метода регистрирует обработчик, который позволяет БСП установить начальное значение счётчика при первом обращении и избежать ошибки получения неинициализированного параметра сеанса.

В модуле `ОбщегоНазначенияПереопределяемый` добавьте вызов внутрь существующей процедуры `ПриДобавленииОбработчиковУстановкиПараметровСеанса`, сохранив остальные подключения. Пример для основной конфигурации:

```bsl
Процедура ПриДобавленииОбработчиковУстановкиПараметровСеанса(Обработчики) Экспорт

    // Другие обработчики параметров сеанса.
    кфкИнтеграция.ПриДобавленииОбработчиковУстановкиПараметровСеанса(Обработчики);

КонецПроцедуры
```

БСП вызывает зарегистрированный обработчик при обращении к неинициализированному параметру; обработчик устанавливает начальное значение счётчика `0`. Для расширения используйте [обработчик с аннотацией `&После`](#extension-setup).

### Подключаемые команды { #connected-commands }

!!! warning "Обязательно при использовании подключаемых команд"
    Если в конфигурации внедрена подсистема БСП «Подключаемые команды», вызов обязателен: он добавляет команду истории выгрузки адаптера в формы объектов.

В процедуре `ПодключаемыеКомандыПереопределяемый.ПриОпределенииКомандПодключенныхКОбъекту` добавьте вызов:

```bsl
кфкИнтеграция.ПриОпределенииКомандПодключенныхКОбъекту(
    НастройкиФормы, Источники, ПодключенныеОтчетыИОбработки, Команды);
```

Метод добавляет команду **«История выгрузки (Kafka)»** в меню **«Еще»** форм объектов, участвующих в интеграции. Видимость команды зависит от функциональной опции `кфкИспользоватьИнтеграцию`.

### При подключении как расширение { #extension-setup }

Заимствуйте соответствующие общие модули БСП в расширение, подключающее адаптер. Для каждой процедуры создайте обработчик с аннотацией `&После`, указав имя процедуры БСП, и разместите в нем соответствующий вызов `кфкИнтеграция`.

Примеры находятся в проекте [examples](https://github.com/ShadobaAI/kafka-adapter-examples):

- `РегламентныеЗаданияПереопределяемый.кфк_т_ПриОпределенииНастроекРегламентныхЗаданий`;
- `ОбщегоНазначенияПереопределяемый.кфк_т_ПриДобавленииОбработчиковУстановкиПараметровСеанса`;
- `ПодключаемыеКомандыПереопределяемый.кфк_т_ПриОпределенииКомандПодключенныхКОбъекту` — если внедрена подсистема БСП «Подключаемые команды».

Примеры ниже взяты из тестового расширения `examples`. В своём расширении используйте принятый в нём префикс имени обработчика.

**Регламентные задания:** в заимствованном модуле `РегламентныеЗаданияПереопределяемый`:

```bsl
&После("ПриОпределенииНастроекРегламентныхЗаданий")
Процедура кфк_т_ПриОпределенииНастроекРегламентныхЗаданий(Настройки) Экспорт

    кфкИнтеграция.ПриОпределенииНастроекРегламентныхЗаданий(Настройки);

КонецПроцедуры
```

**Параметры сеанса:** в заимствованном модуле `ОбщегоНазначенияПереопределяемый`:

```bsl
&После("ПриДобавленииОбработчиковУстановкиПараметровСеанса")
Процедура кфк_т_ПриДобавленииОбработчиковУстановкиПараметровСеанса(Обработчики) Экспорт

    кфкИнтеграция.ПриДобавленииОбработчиковУстановкиПараметровСеанса(Обработчики);

КонецПроцедуры
```

**Подключаемые команды:** если подсистема БСП внедрена, в заимствованном модуле `ПодключаемыеКомандыПереопределяемый`:

```bsl
&После("ПриОпределенииКомандПодключенныхКОбъекту")
Процедура кфк_т_ПриОпределенииКомандПодключенныхКОбъекту(НастройкиФормы, Источники, ПодключенныеОтчетыИОбработки, Команды) Экспорт

    кфкИнтеграция.ПриОпределенииКомандПодключенныхКОбъекту(НастройкиФормы, Источники, ПодключенныеОтчетыИОбработки, Команды);

КонецПроцедуры
```

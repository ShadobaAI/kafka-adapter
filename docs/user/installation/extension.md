# Подключение как расширение конфигурации

Скачайте релиз адаптера. Для Конфигуратора нужен `kafka-adapter.cfe`, для EDT — `kafka-adapter-cfe-edt.zip`. Состав поставки приведён на странице [Форматы поставки](../../project/delivery-formats.md).

=== "Конфигуратор"

    1. Откройте **Конфигурация → Расширения конфигурации**.
    2. Создайте расширение и загрузите в него `kafka-adapter.cfe` командой **Загрузить конфигурацию из файла**.
    3. Выполните [адаптацию подсистемы](adaptation.md#extension-setup).
    4. Обновите конфигурацию базы данных для расширения.

=== "EDT"

    1. Импортируйте `kafka-adapter-cfe-edt.zip` через **File → Import → General → Projects from Folder or Archive**.
    2. Свяжите проект расширения с проектом целевой конфигурации.
    3. Выполните [адаптацию подсистемы](adaptation.md#extension-setup) и разверните расширение на информационной базе.

Назначьте [роли и права](roles.md), затем [включите подсистему](../configuration/index.md#enable-integration). Для больших очередей проверьте [дополнительные индексы](../operations/performance.md#additional-indexes).

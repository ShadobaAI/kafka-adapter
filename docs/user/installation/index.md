# Установка и подключение

Сначала [проверьте требования](requirements.md), затем выберите способ установки и скачайте соответствующий файл из [GitHub Releases](https://github.com/ShadobaAI/kafka-adapter/releases).

## Сравнение вариантов { #compare-installation }

| Вариант | Что подключаете | Инструкция |
|---|---|---|
| Расширение | Файл `kafka-adapter.cfe` или проект EDT расширения. Способ удобен, когда основную конфигурацию нужно обновлять отдельно от адаптера. | [Подключить расширение](extension.md) |
| Основная конфигурация | Объекты из `kafka-adapter.cf` или проекта EDT. При обновлении адаптера потребуется согласовать изменения объединённых объектов. | [Встроить в конфигурацию](main-config.md) |

Исходные архивы EDT, XML и демонстрационная ИБ перечислены на странице [Форматы поставки](../../project/delivery-formats.md). Условия для дополнительных индексов приведены в [разделе о производительности](../operations/performance.md#additional-indexes).

## После установки { #after-installation }

1. [Адаптируйте подсистему](adaptation.md) к справочнику пользователей и подсистемам БСП целевой конфигурации.
2. [Назначьте роли](roles.md) операторам и пользователю обмена.
3. [Включите интеграцию и настройте подключение](../configuration/index.md).

Если в базе уже установлен адаптер, используйте [инструкцию по обновлению](updating.md).

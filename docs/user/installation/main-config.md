# Подключение в основную конфигурацию

Для встраивания используйте `kafka-adapter.cf` или `kafka-adapter-cf-edt.zip` из релиза. Выберите состав объектов подсистемы, проверьте зависимости и согласуйте слияние с режимом поддержки целевой конфигурации. [Форматы поставки](../../project/delivery-formats.md) · [Состав метаданных](../../project/metadata.md)

=== "Конфигуратор"

    1. Откройте целевую конфигурацию и выполните **Конфигурация → Сравнить, объединить с конфигурацией из файла**.
    2. Выберите `kafka-adapter.cf`. В окне сравнения отберите объекты адаптера и проверьте зависимости.
    3. Выполните объединение и [адаптацию подсистемы](adaptation.md).
    4. Обновите конфигурацию базы данных.

=== "EDT"

    1. Импортируйте проект из `kafka-adapter-cf-edt.zip`.
    2. Перенесите объекты адаптера в проект целевой конфигурации через сравнение и объединение.
    3. Выполните [адаптацию подсистемы](adaptation.md) и разверните конфигурацию на информационной базе.

Назначьте [роли и права](roles.md), затем [включите подсистему](../configuration/index.md#enable-integration). Условия создания дополнительных индексов приведены в [разделе о производительности](../operations/performance.md#additional-indexes).

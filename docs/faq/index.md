# Частые вопросы

## Установка и подключение { #installation }

### Какие платформа и БСП нужны?

Платформа 1С:Предприятие 8.3.26 или новее, БСП 3.1.10 или новее и клиент-серверная ИБ. [Требования](../user/installation/requirements.md)

### Подключать расширением или встраивать?

Для отдельного обновления адаптера используйте расширение. Для встраивания перенесите его объекты в целевую конфигурацию и согласуйте последующее обновление с её поддержкой. [Сравнение вариантов](../user/installation/index.md#compare-installation)

### Откуда берётся внешняя компонента?

Simple Kafka Connector 1C входит в поставку адаптера. [Форматы поставки](../project/delivery-formats.md)

### Какие права нужны?

Для просмотра используйте `кфкБазовыеПрава`, для администрирования — `кфкПолныеПрава`. Для пользователя обмена нужны также права, требуемые прикладными обработчиками. [Матрица ролей](../user/installation/roles.md#assigning-roles)

## Настройка обмена { #configuration }

### Где указать SASL и TLS? { #secure-connection }

В справочнике **Брокеры**, в таблице **Параметры подключения**. [Примеры SASL и TLS](../user/examples/secure-connection.md)

### Что означает «Topic authorization failed»? { #topic-authorization }

Проверьте существование топика, точность имени и права учётной записи, под которой входит адаптер. [Порядок проверки доступа](../user/operations/troubleshooting.md#topic-authorization)

### Где указать каталог файловых логов? { #log-directory }

Укажите каталог на сервере 1С с правом записи для серверных процессов. [Файловые логи компоненты](../user/configuration/logging.md#connector-logging)

### Когда применяются изменённые настройки? { #settings-not-applied }

При запуске новых потоков. Для отслеживаемых настроек регламентное задание начинает перезапуск не раньше чем через минуту после их последней записи. При ручном управлении используйте **Перезапустить**. [Условия перезапуска](../user/configuration/jobs.md#settings-restart)

### Почему два консьюмера получают разные записи?

Участники одной группы делят разделы топика. Для независимого чтения создайте разные группы. [Настройки группы](../user/configuration/consumers.md#consumer-groups)

## Разработка интеграции { #integration }

### Какие модули использовать в прикладном коде?

Серверные методы находятся в `кфкИнтеграция`. Для открытия истории из формы используйте `кфкИнтеграцияКлиент`. [Справочник API](../user/development/api.md)

### Как отправить событие без записи объекта 1С?

Задайте в продюсере прикладной ключ регистрации и передайте его в `ПоместитьВОчередьИсходящих`. [Пример произвольного события](../user/examples/custom-events.md)

### Как избежать отправки данных обратно после загрузки?

Вызовите `кфкИнтеграция.Отключить` перед записью объекта или набора, участвующего в исходящем обмене. [Подавление регистрации](../user/examples/suppress.md)

### Как подождать другой объект во входящем обработчике?

Установите `Отказ = Неопределено`. Если зависимость ещё недоступна, можно указать задержку в `Свойства.ВремяОжидания`. [Правила повтора](../user/development/consumer-handler.md#deferred-retry) · [Пример с заказом](../user/examples/incoming-deferred-retry.md)

### Как выполнить отправку или чтение без очереди?

Вызовите `Отправить` или `Прочитать`. Для повторных вызовов можно переиспользовать сессии. [Прямой API](../user/development/direct-api.md)

### Где описаны AsyncAPI, XDTO и КД 3.1?

Выберите нужный справочник в разделе [Контракты сообщений](../user/development/index.md#message-contracts). [Настройка КД 3.1](../user/development/conversion-data.md)

## Эксплуатация и ошибки { #operations }

### Сообщение осталось в статусе «Новое». Что проверить?

Проверьте запуск задания и блокировки. У входящей записи также проверьте поле **Задержка, с**. [Порядок диагностики](../user/operations/troubleshooting.md#new-messages-stuck)

### Какие ошибки повторяются автоматически?

Для исходящей ошибки выгрузки доступны до трёх попыток вместе с первой. Ошибка обработки требует ручного запуска или возврата в очередь. [Автоматический повтор](../user/operations/statuses.md#automatic-retry)

### Где посмотреть причину ошибки?

Начните с поля **Текст журнала** в карточке сообщения. Для ошибок заданий и подписок откройте журнал регистрации 1С. [Источники диагностики](../user/operations/diagnostics.md)

### Как очистить локальную очередь?

Остановите обмен, дождитесь завершения потоков и воспользуйтесь командой удаления в списке очереди. [Способы очистки](../user/operations/queue-maintenance.md#manual-queue-cleanup)

## Разработка адаптера { #contributors }

### С чего начать работу с исходниками?

Соберите рабочий каталог по [карте репозиториев](../project/repositories.md) и [подготовьте окружение](../project/environment.md).

### Где искать задачи и результаты тестов? { #current-tasks }

Задачи ведутся в [kfk-tasks](https://github.com/ShadobaAI/kfk-tasks/issues). Для тестов есть отдельные контуры и опубликованные отчёты. [Тестовые репозитории и отчёты](../project/repositories.md#testing)

### Куда сообщить об ошибке или предложении?

Откройте issue в репозитории адаптера. [Что приложить к описанию](../project/contributing.md#report-bug)

# Из 1С в Kafka

Этот маршрут помогает настроить отправку данных из прикладного решения в топик Kafka через исходящую очередь адаптера.

**Поток:** 1С → регистрация в очереди → обработчик продюсера → Kafka.

## 1. Подключите адаптер

Проверьте [требования](../user/installation/requirements.md) и [установите адаптер](../user/installation/index.md) как расширение либо часть основной конфигурации. Выполните необходимую [адаптацию](../user/installation/adaptation.md) и назначьте [права](../user/installation/roles.md).

Откройте **Kafka / Администрирование** и нажмите **Включить подсистему** — [инструкция по включению](../user/configuration/index.md).

## 2. Подключитесь к Kafka

Создайте [брокер](../user/configuration/brokers.md), укажите bootstrap-серверы в формате `host:port` и параметры подключения. Для защищённого кластера используйте пример [SASL и SSL/TLS](../user/examples/secure-connection.md).

## 3. Настройте продюсер и обработчик

Создайте диспетчер задач и [продюсер](../user/configuration/producers.md). Укажите брокер, топик, ключ регистрации в поле **Тип объект** и способ сериализации.

- Для произвольного обработчика используйте [контракт обработчика продюсера](../user/development/producer-handler.md).
- Для обмена через КД 3.1 используйте [инструкцию по конвертации данных](../user/development/conversion-data.md).
- Для первого примера возьмите [сериализацию справочника](../user/examples/outgoing-catalog.md) или [документ с табличной частью](../user/examples/outgoing-document.md).

При автоматической регистрации поле **Тип объект** должно совпадать с полным именем метаданных. Для событий, регистрируемых только из кода, задайте произвольный ключ и передавайте его через API — [произвольные события](../user/examples/custom-events.md).

## 4. Запустите фоновые задания

На вкладке **Kafka / Администрирование / Регламентное задание** включите **Использовать**, задайте расписание и пользователя обмена. Убедитесь, что обмен не заблокирован на вкладке **Фоновые задания**. Требования к правам, серверу и ограничения БСП описаны в разделе [Фоновые и регламентные задания](../user/configuration/jobs.md).

## 5. Проверьте отправку

Запишите объект, участвующий в интеграции, или выполните [регистрацию через API](../user/examples/force-registration.md). Откройте **Исходящие сообщения**, проверьте [статус](../user/operations/statuses.md) и историю выгрузки, затем убедитесь в появлении сообщения в нужном топике Kafka.

[Мониторинг очередей](../user/operations/monitoring.md) объясняет, где смотреть результат. Если сообщение осталось в очереди или получило ошибку, откройте [типовые проблемы](../user/operations/troubleshooting.md) и [диагностику](../user/operations/diagnostics.md).

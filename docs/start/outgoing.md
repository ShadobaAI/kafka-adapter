# Из 1С в Kafka

[Подготовьте адаптер, брокер и тестовый топик](index.md#prerequisites). Для первого обмена удобно публиковать изменения одного справочника.

## Настройте выгрузку { #configure }

1. В списке **Продюсеры** создайте диспетчер задач, затем продюсер в этой группе. Укажите настроенный брокер.
2. В таблице **Объекты метаданных** добавьте полное имя объекта в **Тип объект** и укажите топик. Выберите тип **Произвольный обработчик** и задайте имя экспортной функции. [Настройки продюсера](../user/configuration/producers.md)
3. Добавьте функцию по [примеру сериализации справочника](../user/examples/outgoing-catalog.md). Если публикуете уже подготовленное тело, используйте [пример готового сообщения](../user/examples/custom-events.md).
4. Включите [регламентное задание](../user/configuration/jobs.md#scheduled-job) и проверьте, что обмен разблокирован.

## Проверьте результат { #verify }

Запишите элемент справочника. Откройте **Kafka → Исходящие сообщения**, найдите запись объекта и дождитесь статуса **Выгружено**. Затем проверьте ключ и тело записи в выбранном топике Kafka.

Если запись отсутствует или не выгружается, [найдите этап сбоя](../user/operations/diagnostics.md). Для обратного направления перейдите к [загрузке из Kafka](incoming.md).

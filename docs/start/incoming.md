# Из Kafka в 1С

Этот маршрут помогает настроить чтение топика Kafka и обработку входящих сообщений в прикладном решении.

**Поток:** Kafka → чтение консьюмером → входящая очередь → обработчик → 1С.

## 1. Подключите адаптер

Проверьте [требования](../user/installation/requirements.md) и [установите адаптер](../user/installation/index.md) как расширение либо часть основной конфигурации. Выполните необходимую [адаптацию](../user/installation/adaptation.md) и назначьте [права](../user/installation/roles.md).

Откройте **Kafka / Администрирование** и нажмите **Включить подсистему** — [инструкция по включению](../user/configuration/index.md).

## 2. Подключитесь к Kafka

Создайте [брокер](../user/configuration/brokers.md), укажите bootstrap-серверы и параметры подключения. Для защищённого кластера используйте пример [SASL и SSL/TLS](../user/examples/secure-connection.md).

Для проверки получения понадобятся сообщения в выбранном топике Kafka.

## 3. Настройте консьюмер и обработчик

Создайте диспетчер задач и [консьюмер](../user/configuration/consumers.md). Укажите брокер, **Идентификатор** группы консьюмеров, топик и способ десериализации.

Консьюмеры одной группы делят поток между собой. Если несколько потребителей должны получать независимый полный поток, используйте разные идентификаторы групп — [подробности настройки](../user/configuration/consumers.md).

- Для произвольного обработчика используйте [контракт обработчика консьюмера](../user/development/consumer-handler.md).
- Для обмена через КД 3.1 используйте [инструкцию по конвертации данных](../user/development/conversion-data.md).
- Для первого примера возьмите [создание или обновление справочника](../user/examples/incoming-catalog.md) либо [запись в регистр сведений](../user/examples/incoming-register.md).

При записи данных из входящего сообщения подавляйте исходящую регистрацию по правилам примера [Upsert справочника](../user/examples/incoming-catalog.md), чтобы не запустить обмен по кругу.

## 4. Запустите фоновые задания

На вкладке **Kafka / Администрирование / Регламентное задание** включите **Использовать**, задайте расписание и пользователя обмена. Убедитесь, что обмен не заблокирован на вкладке **Фоновые задания**. Требования к правам, серверу и ограничения БСП описаны в разделе [Фоновые и регламентные задания](../user/configuration/jobs.md).

## 5. Проверьте получение

Отправьте тестовое сообщение в топик, на который подписан консьюмер. Откройте **Входящие сообщения**, проверьте [статус](../user/operations/statuses.md), журнал обработки и результат в данных 1С.

В разделе [Мониторинг очередей](../user/operations/monitoring.md) описаны инструменты проверки. Если сообщения не поступают, проверьте блокировку чтения, имя топика, группу и смещения по инструкции [Типовые проблемы](../user/operations/troubleshooting.md).

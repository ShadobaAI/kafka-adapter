# Из Kafka в 1С

[Подготовьте адаптер, брокер и тестовый топик](index.md#prerequisites). Для первого обмена выберите собственную группу консьюмеров, чтобы её смещения не пересекались с действующей интеграцией.

## Настройте загрузку { #configure }

1. В списке **Консьюмеры** создайте диспетчер задач, затем консьюмер. Укажите брокер и **Идентификатор** группы. [Как работают группы](../user/configuration/consumers.md#consumer-groups)
2. Добавьте топик, выберите **Произвольный обработчик** и укажите имя экспортной процедуры. Для тела в виде строки JSON выключите **Двоичные данные**. [Настройки консьюмера](../user/configuration/consumers.md)
3. Добавьте процедуру по [примеру загрузки справочника](../user/examples/incoming-catalog.md) или [записи в регистр сведений](../user/examples/incoming-register.md).
4. Включите [регламентное задание](../user/configuration/jobs.md#scheduled-job) и проверьте, что обмен разблокирован.

## Проверьте результат { #verify }

После запуска опубликуйте тестовый JSON. В **Kafka → Входящие сообщения** найдите запись по топику, разделу и смещению. Проверьте статус **Обработано** и результат записи в 1С.

Если сообщений нет, начните с [проверки чтения](../user/operations/troubleshooting.md#no-incoming-messages). Если обработка ждёт загрузки другого объекта, используйте [пример отложенного повтора](../user/examples/incoming-deferred-retry.md).

# Глоссарий Kafka

## Кластер и сообщения { #cluster-and-messages }

| Термин | Значение |
|---|---|
| **Кластер** | Брокеры Kafka, совместно обслуживающие топики. |
| **Брокер** | Узел Kafka. В справочнике **Брокеры** адаптера один элемент хранит параметры подключения к кластеру. |
| **Топик** | Именованный поток записей. Топик состоит из одного или нескольких разделов. |
| **Запись Kafka** | Ключ, тело и заголовки, если заданы, а также временная метка. Тело передаётся последовательностью байт. |

### Партиция (раздел) { #partition }

Kafka хранит порядок записей внутри раздела. Топик с несколькими разделами можно читать параллельно. Сопоставление ключа с разделом зависит от настроек клиента. [Ключ исходящего сообщения](user/development/producer-handler.md#message-key)

### Смещение (offset) { #offset }

Номер записи в разделе. Для поиска конкретной записи нужны топик, раздел и смещение. Зафиксированная позиция чтения хранится по группе, топику и разделу. Локальные позиции фоновых операций в 1С отсчитываются по комбинированным меткам очереди.

## Клиенты Kafka { #clients }

- **Продюсер** публикует записи в топики. [Настройка в 1С](user/configuration/producers.md)
- **Консьюмер** читает записи из топиков. [Настройка в 1С](user/configuration/consumers.md)

### Группа консьюмеров { #consumer-group }

Участники обычной группы Kafka делят назначенные разделы. В один момент раздел назначается одному участнику группы. У разных групп собственные позиции чтения. [Идентификатор группы в адаптере](user/configuration/consumers.md#consumer-groups)

### Bootstrap-серверы { #bootstrap-servers }

Начальные адреса узлов, через которые клиент получает метаданные кластера. Укажите их в [настройках брокера](user/configuration/brokers.md#bootstrap-servers).

[Термины в документации Apache Kafka](https://kafka.apache.org/42/getting-started/introduction/)

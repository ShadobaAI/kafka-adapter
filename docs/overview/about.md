# О проекте

**1С: Адаптер Kafka** добавляет обмен с Apache Kafka в прикладную конфигурацию 1С. Его можно подключить как расширение или встроить в основную конфигурацию. Сравнение вариантов и инструкции находятся в разделе [Установка и подключение](../user/installation/index.md).

Прикладное решение определяет, какие события публиковать, как устроено тело сообщения и какие записи менять при получении. Адаптер подключается к Kafka через Simple Kafka Connector 1C, ведёт очереди в базе 1С и запускает обработку в фоновых заданиях.

## Где подходит адаптер { #use-cases }

- Публиковать изменения справочников, документов и регистров для других систем.
- Формировать сообщения из прикладных событий, у которых нет объекта 1С.
- Получать сообщения из Kafka и передавать их собственному обработчику или правилам Конвертации данных 3.1.

Возможности по направлениям и ссылки на настройку собраны на странице [Возможности адаптера](capabilities.md). Состав подсистемы и границы ответственности описаны в [Архитектуре](architecture.md).

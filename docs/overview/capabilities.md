# Возможности адаптера

| Задача | Что предоставляет адаптер |
|---|---|
| Выгружать данные из 1С | Регистрирует объект при записи или по вызову API. Фоновые задания подготавливают тело и публикуют сообщение в топике. [Настроить выгрузку](../start/outgoing.md) |
| Загружать данные в 1С | Читает топики консьюмером, сохраняет сообщения в очереди и передаёт их прикладному обработчику. [Настроить загрузку](../start/incoming.md) |
| Преобразовывать данные | Вызывает экспортный метод прикладного решения или модуль обмена КД 3.1, использующий XDTO. [Выбрать способ обработки](../user/development/index.md) |
| Отправлять или читать из кода напрямую | Предоставляет API сессий внешней компоненты для работы с Kafka вне очередей. [Прямой API](../user/development/direct-api.md) |
| Разбирать сбои | Сохраняет статусы и журнал записей очередей, поддерживает уведомления и выгрузку логов в настроенный HTTP-приёмник. [Эксплуатация](../user/operations/index.md) |
| Управлять повторной обработкой | Поддерживает дедупликацию исходящих регистраций, проверку хэшей тел и отложенный повтор по запросу входящего обработчика. [Правила и ограничения](principles.md) |

Системные требования, включая версии платформы и БСП, собраны на [странице требований](../user/installation/requirements.md). Путь сообщения через очередь и обработчики показан в разделе [Потоки данных](data-flow.md).

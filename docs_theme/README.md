# Тема документации

Документация собирается MkDocs Material. Иерархия страниц задана в `mkdocs.yml`. Тема добавляет верхнее меню и оглавление статьи. На узком экране оглавление открывается кнопкой **На этой странице**.

- `partials/header.html` и `partials/footer.html` — меню, поиск и переходы по документации.
- `main.html` — оглавление и ширина справочника API.
- `anchors.py` — латинские идентификаторы Markdown-заголовков и вкладок. Для заголовка, на который ссылаются внутри документации, укажите стабильный английский идентификатор, например `## Настройка { #configuration }`. Заголовок остаётся русским.
- `../docs/assets/stylesheets/portal.css` и `extra.css` — типографика, адаптивная вёрстка и окно просмотра схем.
- `../docs/assets/javascripts/portal.js` — поведение меню, поиск и отступ перехода по якорям.
- `../docs/assets/javascripts/mermaid-config.js` — вывод диаграмм Mermaid 11.15.0 с jsDelivr и просмотр с увеличением.

Для схем выбирайте короткие подписи и небольшое число узлов. Добавляйте `accTitle` и `accDescr`. Ключевые этапы должны быть понятны из текста статьи.

## Сборка и локальный просмотр

Из корня репозитория в отдельном окружении Python:

```powershell
python -m pip install -r docs/requirements.txt
python -m mkdocs build --strict
python -m mkdocs serve --dev-addr 127.0.0.1:8000
```

Откройте `http://127.0.0.1:8000/kafka-adapter/`. Строгая сборка проверяет внутренние ссылки и их якоря. Результат сборки в `site/` исключён из Git.

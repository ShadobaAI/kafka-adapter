# Оформление документации

Документация собирается MkDocs Material. Тема портала расширяет Material через
`custom_dir: docs_theme`: верхнее меню заменяет постоянную левую панель, а поиск,
оглавление, подсветка кода, вкладки и схемы продолжают использовать штатные механизмы.

- `partials/header.html` — меню всех разделов, поиск и переключатель темы.
  Меню содержат раскрываемое дерево; ветки текущей страницы открыты автоматически.
  Иерархия задаётся в `mkdocs.yml`, страницы и ссылки сохраняются при перегруппировке.
  Настройка и эксплуатация доступны напрямую из верхнего меню; первый запуск
  вынесен в отдельную ветку, на главной есть быстрые ссылки для текущей работы.
- `partials/footer.html` — соседние страницы и дополнительные ссылки.
- `main.html` — оглавление без постоянной основной боковой навигации.
  Страницы справочника API используют более широкую область сайта и оглавление
  с переносом полных сигнатур; на узких экранах оглавление сворачивается.
- `../docs/assets/stylesheets/portal.css` — палитра, типографика и адаптивная вёрстка.
- `../docs/assets/javascripts/portal.js` — поиск и состояние меню.
- `../docs/assets/javascripts/mermaid-config.js` — загрузка закреплённой версии
  Mermaid 11.15.0 с jsDelivr по необходимости, оформление схем и окно увеличения.
  Схемы выводятся в обычный DOM, поскольку закрытые Shadow DOM Material не позволяют
  перенести SVG в окно просмотра. Markdown-описания диаграмм остаются прежними.
- `../docs/index.md` — главная; `../docs/start/` — оба направления обмена;
  `../docs/faq/` — краткие ответы со ссылками на подробные инструкции.

## Сборка и локальный просмотр

Из корня репозитория, в отдельном окружении Python:

```powershell
python -m pip install -r docs/requirements.txt
python -m mkdocs build --strict
python -m mkdocs serve --dev-addr 127.0.0.1:8000
```

Адрес локального сайта MkDocs выводит при запуске. Сборка создаёт каталог `site/`,
который исключён из Git. Пины зависимостей сохраняются; перед их обновлением
проверяйте строгую сборку. Для индексных страниц разделов используется встроенная
возможность Material `navigation.indexes`.

Переходы между документами используют обычную навигацию браузера: новая страница
открывается с начала, а якоря и возврат назад сохраняют стандартное поведение.

## Сохранность содержания

При переработке структуры сохраняйте технические страницы, явные якоря и полноту
контрактов. Главная служит точкой входа: прежний обзор возможностей, быстрый старт,
описания направлений, ссылки AsyncAPI/XDTO и лицензия сохранены в
`../docs/overview/capabilities.md`. Настройки выгрузки и загрузки рассматриваются
отдельно: `start/outgoing.md` и `start/incoming.md`.
